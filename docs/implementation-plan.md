# خطة التنفيذ وحالة التسليم

ملاحظة ٣١ أكتوبر ٢٠٢٦: هذه وثيقة مرحلة سابقة؛ أي ذكر لأرصدة المخزن أو الجرد أو الحجز الكمي متقاعد منذ 028. راجع operations.md وadmin.md للنموذج الحالي، وmanual-availability-cleanup.md لتنظيف 030.

آخر تحديث: ٢٦ أكتوبر ٢٠٢٦. جميع المراحل أدناه منفذة محليًا؛ لم ينشر إنتاج عام.

## المنفذ

1. الأساس: Next.js وTypeScript وRTL وSupabase على Docker، واختبارات القواعد والمتصفح وأسرار خارج Git.
2. الحسابات والكتالوج والإدارة: الهاتف وكلمة المرور والملف والعناوين والجلسات وحدود المحاولات، الأقسام والمناطق والإعدادات والمنتجات والأكواد التلقائية ووحدات الجملة والصور والجرد والأرشفة، البحث والفلاتر والفرز والترقيم والتدقيق. الاسترجاع الإداري وتغيير الهاتف وإبطال الجلسات منفذة.
3. الأسعار والعروض: نطاقات الوحدة والمنتج والقسم والكل، العميل والكمية والنسبة أو السعر الثابت والفترة الزمنية، ومعاينة أقل سعر مؤهل دون تكديس.
4. الطلبات: السلة والمراجعة والإرسال والحجز الذري ومنع التكرار، تنافس آخر كمية، الحالات والتسليم والإلغاء والتحصيل والرد، تاريخ العميل وإعادة الطلب بأسعار حالية.
5. التشغيل: استيراد Excel محدود مع المعاينة والاعتماد الذري وسجل الدفعات، التصديرات المجزأة والتقارير الفعلية، وإدارة أذونات الموظفين.

## الترحيلات والتحقق

ترحيلات supabase/migrations من 001 إلى 018 مطبقة بالتتابع على قاعدة التطوير القائمة دون إعادة ضبطها: الأساس والحسابات والإدارة والأكواد والصور، ثم الطلبات والتسعير والتشغيل والاسترجاع والاستيراد والتقارير وفلاتر الكتالوج وحد إرسال الطلبات وقيود الأدوار وتحسين الاستعلامات والفهارس وتجميع التقارير بالهوية الثابتة. ملفات SQL هي المرجع التنفيذي للأسماء والقيود والمنح.

نجح البناء وlint وTypeScript، و١٨٢ اختبار قواعد وSQL و٢٨ اختبار متصفح متصل و٨ اختبارات واجهة إضافية. اختبر الإرسال المتنافس باتصالات فعلية والاسترجاع مع رفض الجلسة القديمة وملفات Excel الفعلية. نجحت استعادة قاعدة البيانات إلى قاعدة جديدة معزولة. نُفذ فحص استعلامات بـ١٠ آلاف منتج ووحدة، ولا يعد اعتماد سعة إنتاجية. التفاصيل في [تقرير التحقق](test-report.md).

## قبل الإصدار العام

المتبقي: استضافة التطبيق وSupabase الإنتاجي والمصادقة والأسرار وHTTPS والمراقبة، سياسة نسخ احتياطي دائمة لقاعدة البيانات وStorage وتجربة استعادة الصور، واختبار HTTP متزامن على موارد مماثلة للإنتاج وتسجيل نقطة التشبع. لا يفترض نشر تلقائي أو ربط Bella أو مزود SMS أو تأكيد InstaPay تلقائي.

الاستيراد الحالي محدود بـ٥٠٠ صف ويطبق تزامنيًا. المهام الخلفية الدائمة وoutbox ومعالجة ملفات أكبر وتحسين اختيار الأقسام بعد ٥٠٠ قسم توسعات مستقبلية، وليست خدمات عاملة في هذه النسخة. لا توجد أرقام سعة مضمونة قبل القياس على الاستضافة.

كل تغيير لاحق يحتاج الاختبارات المناسبة وlint وTypeScript والبناء عند تغيير مصدر مؤثر عليه. لا تطبيق لترحيل مدمر على الإنتاج دون موافقة صريحة ونسخة احتياطية وخطة استعادة.
